a11y-description: "Samples a uniformly random standard Young tableau of rectangular shape 4 by c with the hook walk and computes its three promotion permutations, of which the third is the inverse of the first and the second is a fixed-point-free involution. It then runs the growth algorithm of Gaetz, Pechenik, Pfannerer, Striker and Swanson to build the corresponding SL4 web, a fully reduced hourglass plabic graph whose trip permutations equal the promotion permutations; the page verifies this equality and recovers the tableau from the web. The web is drawn in a disk with a harmonic layout, with vertices at crossings of straight trip-2 chords, or as the growth diagram, which can be stepped through round by round. The three promotion permutations are shown as permutation matrices. Hovering a boundary vertex highlights its three trip strands and the corresponding matrix entries and tableau cells. Controls set c, resample, apply promotion, or accept a user-supplied tableau."

<details class="math-description" id="sl4-defs">
<summary>About this simulation</summary>
<div style="padding: 10px 4px 6px; line-height: 1.55;">

<p><b>Tableaux and lattice words.</b> A standard Young tableau $T$ of rectangular shape $4\times c$ is encoded by its lattice word $w=w_1\cdots w_n$, $n=4c$, where $w_k\in\{1,2,3,4\}$ is the row containing $k$. A uniformly random $T$ is sampled with the Greene–Nijenhuis–Wilf hook walk. Their number is the dimension of the $\mathrm{SL}_4$-invariant space $\mathrm{Inv}(V^{\otimes n})$.</p>

<p><b>Promotion permutations.</b> Promotion $\mathcal P$ removes $1$, slides by jeu de taquin, inserts $n+1$ and subtracts $1$. On lattice words, with $j_0=1$ and $j_i$ the first index $\ge j_{i-1}$ at which the prefix $w_1\cdots w_{j_i}$ has as many letters $i$ as $i+1$, promotion deletes $w_1$, changes $w_{j_i}=i+1$ to $i$ for $i=1,2,3$, and appends $4$. The entry $j_i$ is the one that crosses from row $i+1$ into row $i$. Following [GPPSS, Promotion permutations], $\mathrm{prom}_i(T)(b)\equiv j_i(\mathcal P^{b-1}T)+b-1 \pmod n$. Then $\mathrm{prom}_3=\mathrm{prom}_1^{-1}$, $\mathrm{prom}_2$ is a fixed-point-free involution, the antiexcedances of $\mathrm{prom}_i$ are exactly the entries in rows $1,\ldots,i$ (so $\mathrm{prom}_1,\mathrm{prom}_2$ determine $T$), and $\mathrm{prom}_i(\mathcal P T)=\sigma^{-1}\mathrm{prom}_i(T)\,\sigma$ for the long cycle $\sigma$. The panels show the permutation matrices: row $b$, column $\mathrm{prom}_i(b)$.</p>

<p><b>Hourglass plabic graphs.</b> An hourglass plabic graph is a bipartite planar graph in a disk with boundary vertices $b_1,\ldots,b_n$ clockwise and all internal vertices of degree $4$ counted with multiplicity; an edge of multiplicity $2$ is an <em>hourglass</em>, twisted so that its two strands have the same clockwise order at both ends. The trip permutation $\mathrm{trip}_a$ follows the strand from $b_i$ taking the $a$-th left turn at white vertices and the $a$-th right turn at black vertices. A graph is fully reduced if no graph in its move class (benzene, square and contraction moves) has a $4$-cycle through an hourglass; square faces of simple edges are allowed, and they are where square moves act. Move classes of fully reduced graphs correspond bijectively to $4$-row rectangular (fluctuating) tableaux with $\mathrm{trip}_\bullet(G)=\mathrm{prom}_\bullet(T)$, so promotion becomes rotation up to moves. The rotation-invariant $\mathrm{SL}_4$ web basis of [GPPSS, Invent. Math.] takes the <em>top</em> graph of each class, the one with no clockwise benzene face; the growth output drawn here is fully reduced and in the right class, but may differ from that basis web by benzene moves. For standard $T$ all boundary vertices are black.</p>

<p><b>Growth rules.</b> The map $T\mapsto G$ is the growth algorithm of [GPPSS, §5]. Put $n$ dangling strands labeled $w_1,\ldots,w_n$ on a line, pointing down. Repeatedly replace a factor of the word of dangling labels by a crossing ($\mathsf X$) of two adjacent strands or a cap $1\bar 1\to\varnothing$, $\bar 44\to\varnothing$, using the $88$ short rules (length $2$ or $3$; in a rule of length $3$ two adjacent strands cross and the remaining letter, on the left or on the right, is an unchanged <em>witness</em>) and two families of long rules $14uw\to 41uw$ ($u$ any word in $\bar2,\bar3$, $w\in\{\bar1,2,3,4\}$) and $23uw\to\bar1\bar4uw$ ($u$ any word in $2,3$, $w\in\{\bar1,\bar2,\bar3,4\}$), with their images under the symmetries, which put the witnesses on the left. Barred labels are strands pointing up. Every sequence of choices terminates. The result is a symmetrized six-vertex configuration: every crossing is a sink, a source, or transmitting (two adjacent edges in, two out). Sinks become white vertices, sources black vertices, and a transmitting crossing becomes a white and a black vertex joined by an hourglass. The edge labels form the growth labeling, a proper labeling of the web with boundary word $w$. Here the rules are applied in rounds, scanning left to right; the <b>Growth</b> view shows the rounds, and the step slider replays them with the dangling labels.</p>

<p><b>What the page checks.</b> For every sample it computes $\mathrm{prom}_\bullet(T)$ from the tableau and $\mathrm{trip}_\bullet(G)$ from the web independently and compares them, and it recovers $T$ from the web through the antiexcedances of $\mathrm{trip}_\bullet$ (the map $\mathcal T$ of [GPPSS]). The core code was also checked exhaustively for all $24\,024$ standard tableaux of shape $4\times 4$ and on random tableaux up to $c=60$.</p>

<p><b>Views.</b> <em>Disk</em>: Tutte's harmonic embedding, boundary on the circle and each crossing at the average of its neighbours. <em>Chords</em>: each crossing is the meeting point of the straight chords of its two $\mathrm{trip}_2$ strands, which pass straight through every crossing and pairwise cross at most once, so the web becomes the chord diagram of the matching $\mathrm{prom}_2$; the slider hides strands of cyclic length below a threshold. <em>Growth</em>: the growth diagram, boundary on top. The mark at the top of the circle is the base face, between $b_n$ and $b_1$. Hover a boundary vertex, a matrix row or a tableau cell to see the $\mathrm{trip}_1$ (purple), $\mathrm{trip}_2$ (orange) and $\mathrm{trip}_3$ (green) strands from $b_i$; click to pin. Zoom the web with the + / − buttons, ⌘/Ctrl + scroll, or a trackpad pinch; drag to pan; double-click to reset.</p>

<p><b>Large $c$.</b> In simulations the empirical permuton of $\mathrm{prom}_i$ concentrates on the diagonal, with the wrap-around at the corners: the fraction of $b$ with cyclic distance $|\mathrm{prom}_1(b)-b|>n/20$ is about $0.45,\,0.25,\,0.13,\,0.07$ for $n=100,400,1600,6400$, roughly $n^{-1/2}$, as for the noncrossing matching of a random Dyck path ($r=2$). Accordingly $\mathrm{inv}(\mathrm{prom}_1)/n^2\approx 0.133,\,0.080,\,0.043,\,0.024,\,0.012$ for $n=100,400,1600,6400,25600$, consistent with $\mathrm{inv}(\mathrm{prom}_i)\asymp n^{3/2}$: about $\sqrt n$ macroscopic jumps, each carrying order $n$ inversions. The large-scale structure sits in the few long $\mathrm{trip}_2$ chords, which the <em>Chords</em> view with a length threshold isolates.</p>

  function clipPolylineY(pts, ymax) {
    // keep the part with y <= ymax (pts in world coordinates); returns array of polylines
    const res = [];
    let cur = [];
    for (let k = 0; k < pts.length; k += 2) {
      const x = pts[k], y = pts[k + 1];
      if (y <= ymax + 1e-9) {
        if (cur.length === 0 && k > 0) {
          const px = pts[k - 2], py = pts[k - 1];
          if (py > ymax) { const t = (ymax - py) / (y - py); cur.push(px + t * (x - px), ymax); }
        }
        cur.push(x, y);
      } else if (cur.length) {
        const px = pts[k - 2], py = pts[k - 1];
        const t = (ymax - py) / (y - py);
        cur.push(px + t * (x - px), ymax);
        res.push(cur); cur = [];
      }
    }
    if (cur.length >= 4) res.push(cur);
    return res;

    // dangling strands at the cut
    if (partial && G.roundWords) {
      const xs = G.roundX[S.round], labs = G.roundWords[S.round];
      ctx.strokeStyle = C.accent;
      ctx.setLineDash([4, 4]);
      ctx.lineWidth = 1;
      ctx.beginPath();
      ctx.moveTo(T.sx(L.bbox[0]) - 10, T.sy(ycut)); ctx.lineTo(T.sx(L.bbox[2]) + 10, T.sy(ycut));
      ctx.stroke();
      ctx.setLineDash([]);
      const step = xs.length > 1 ? Math.abs(T.sx(xs[1]) - T.sx(xs[0])) : 20;
      if (step >= 9) {
        ctx.fillStyle = C.accent;
        ctx.font = Math.min(14, Math.max(9, step * 0.6)) + 'px "SF Mono", Monaco, monospace';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'top';
        for (let k = 0; k < xs.length; k++) {
          const X = T.sx(xs[k]), Y = T.sy(ycut) + 4;
          const l = labs[k];
          ctx.fillText(String(Math.abs(l)), X, Y);
          if (l < 0) {
            const wch = ctx.measureText('0').width;
            ctx.fillRect(X - wch / 2, Y - 2, wch, 1.2);
          }
        }
      }
    }

    // vertices and hourglasses
    const showV = $('sl4Verts').checked;
    if (showV) {
      ctx.globalAlpha = sel >= 0 ? 0.55 : 1;
      for (let x = 0; x < G.nx; x++) {
        if (G.xtype[x] !== W.TRANS || crossHidden(x)) continue;
        if (partial && G.ypos[x] * gy > ycut) continue;
        const Wv = H.wOf[x], Bv = H.bOf[x];
        const ax = T.sx(L.hp[2 * Wv]), ay = T.sy(L.hp[2 * Wv + 1]);
        const bx = T.sx(L.hp[2 * Bv]), by = T.sy(L.hp[2 * Bv + 1]);
        const len = Math.hypot(bx - ax, by - ay);
        ctx.strokeStyle = C.ink;
        if (len < 7) {
          ctx.lineWidth = Math.max(lw * 2.2, 1.6);
          ctx.beginPath(); ctx.moveTo(ax, ay); ctx.lineTo(bx, by); ctx.stroke();
        } else {
          const nx_ = -(by - ay) / len, ny_ = (bx - ax) / len, w = Math.min(len * 0.32, 6);
          ctx.lineWidth = Math.max(lw, 1);
          ctx.beginPath();
          ctx.moveTo(ax + nx_ * w, ay + ny_ * w); ctx.lineTo(bx - nx_ * w, by - ny_ * w);
          ctx.moveTo(ax - nx_ * w, ay - ny_ * w); ctx.lineTo(bx + nx_ * w, by + ny_ * w);
          ctx.stroke();
        }
      }
      // white and black internal vertices
      const drawNodes = (white) => {
        ctx.beginPath();
        for (let v = n; v < H.N; v++) {
          if ((H.color[v] < 0) !== white) continue;
          const x = H.owner[v];
          if (crossHidden(x)) continue;
          if (partial && G.ypos[x] * gy > ycut) continue;
          const X = T.sx(L.hp[2 * v]), Y = T.sy(L.hp[2 * v + 1]);
          ctx.moveTo(X + vr, Y);
          ctx.arc(X, Y, vr, 0, 2 * Math.PI);
        }
        if (white) {
          ctx.fillStyle = C.bg; ctx.fill();
          ctx.lineWidth = Math.max(0.8, vr * 0.35); ctx.strokeStyle = C.ink; ctx.stroke();
        } else {
          ctx.fillStyle = C.ink; ctx.fill();
        }
      };
      drawNodes(true);
      drawNodes(false);
      ctx.globalAlpha = 1;
    }

    // boundary vertices
    const bgap = growth ? T.k : 2 * Math.PI * T.k / n;
    const br = Math.max(0.8, Math.min(5, vr * 1.05, bgap * 0.4));
    ctx.fillStyle = C.ink;
    ctx.beginPath();
    for (let i = 0; i < n; i++) {
      const X = T.sx(L.bp[2 * i]), Y = T.sy(L.bp[2 * i + 1]);
      ctx.moveTo(X + br, Y);
      ctx.arc(X, Y, br, 0, 2 * Math.PI);
    }
    ctx.fill();

    // boundary indices
    const bstep = growth ? Math.abs(T.sx(1) - T.sx(0)) : 2 * Math.PI * T.k / n;
    if (bstep >= 13) {
      ctx.fillStyle = C.muted;
      ctx.font = Math.min(12, bstep * 0.55) + 'px "franklingothic-book", Arial, sans-serif';
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      for (let i = 0; i < n; i++) {
        let X, Y;
        if (growth) { X = T.sx(L.bp[2 * i]); Y = T.sy(0) - 12; }
        else { X = T.sx(L.bp[2 * i] * 1.07); Y = T.sy(L.bp[2 * i + 1] * 1.07); }
        ctx.fillText(String(i + 1), X, Y);
      }
    }

    // edge labels
    if ($('sl4Labels').checked) {
      ctx.font = 'bold 11px "SF Mono", Monaco, monospace';
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      for (let e = 0; e < G.eu.length; e++) {
        if (edgeHidden(e)) continue;
        const pts = edgeWorldPts(e, L);
        // midpoint by arclength in screen space
        let tot = 0;
        const sp = [];
        for (let k = 0; k < pts.length; k += 2) sp.push(T.sx(pts[k]), T.sy(pts[k + 1]));
        for (let k = 2; k < sp.length; k += 2) tot += Math.hypot(sp[k] - sp[k - 2], sp[k + 1] - sp[k - 1]);
        if (tot < 14) continue;
        let acc = 0, mx = sp[0], my = sp[1];
        for (let k = 2; k < sp.length; k += 2) {
          const d = Math.hypot(sp[k] - sp[k - 2], sp[k + 1] - sp[k - 1]);
          if (acc + d >= tot / 2) { const t = (tot / 2 - acc) / d; mx = sp[k - 2] + t * (sp[k] - sp[k - 2]); my = sp[k - 1] + t * (sp[k + 1] - sp[k - 1]); break; }
          acc += d;
        }
        if (partial && T.wy(my) > ycut) continue;
        ctx.fillStyle = C.bg;
        ctx.fillRect(mx - 5, my - 6, 10, 12);
        ctx.fillStyle = colorLab ? C.lab[G.elab[e]] : C.accent;
        ctx.fillText(String(G.elab[e]), mx, my);
      }
    }

    // trip strands of the selected boundary vertex
    if (sel >= 0) drawTrips(ctx, L, sel, partial ? ycut : null);
  }

  function tripWorldPolyline(a, i, L) {
    const path = S.web.trips[a].paths[i];
    const out = [];
    const H = S.web.H;
    for (let k = 0; k + 1 < path.length; k += 2) {
      const f = path[k], t = path[k + 1];
      const e = S.edgeAtHG[f];
      let pts;
      if (e >= 0 && (S.eA[e] === f || S.eB[e] === f)) {
        pts = edgeWorldPts(e, L);
        if (S.eA[e] !== f) {
          const r = [];
          for (let q = pts.length - 2; q >= 0; q -= 2) r.push(pts[q], pts[q + 1]);
          pts = r;
        }
      } else {
        pts = [L.hp[2 * (f >> 2)], L.hp[2 * (f >> 2) + 1], L.hp[2 * (t >> 2)], L.hp[2 * (t >> 2) + 1]];
      }
      for (let q = (out.length ? 2 : 0); q < pts.length; q++) out.push(pts[q]);
    }
    return out;
  }

  function offsetPolyline(sp, off) {
    const m = sp.length / 2;
    if (m < 2 || off === 0) return sp;
    const out = new Array(sp.length);
    for (let k = 0; k < m; k++) {
      let nx = 0, ny = 0;
      for (const [p, q] of [[k - 1, k], [k, k + 1]]) {
        if (p < 0 || q >= m) continue;
        const dx = sp[2 * q] - sp[2 * p], dy = sp[2 * q + 1] - sp[2 * p + 1];
        const d = Math.hypot(dx, dy);
        if (d > 1e-9) { nx += dy / d; ny += -dx / d; }
      }
      const d = Math.hypot(nx, ny) || 1;
      out[2 * k] = sp[2 * k] + off * nx / d;
      out[2 * k + 1] = sp[2 * k + 1] + off * ny / d;
    }
    return out;
  }

  // ycut: in the growth view stepped back to an earlier round, draw only the part above the cut
  function drawTrips(ctx, L, i, ycut) {
    const offs = [-3, 0, 3];
    for (const a of [1, 0, 2]) {
      const wp = tripWorldPolyline(a, i, L);
      const pieces = ycut === null ? [wp] : clipPolylineY(wp, ycut);
      let sp = [];
      ctx.strokeStyle = C.t[a];
      ctx.lineWidth = a === 1 ? 3.2 : 2.4;
      ctx.globalAlpha = 0.95;
      for (const piece of pieces) {
        sp = [];
        for (let k = 0; k < piece.length; k += 2) sp.push(T.sx(piece[k]), T.sy(piece[k + 1]));
        // drop repeated points
        const clean = [sp[0], sp[1]];
        for (let k = 2; k < sp.length; k += 2) {
          if (Math.hypot(sp[k] - clean[clean.length - 2], sp[k + 1] - clean[clean.length - 1]) > 0.5) clean.push(sp[k], sp[k + 1]);
        }
        sp = offsetPolyline(clean, offs[a]);
        ctx.beginPath();
        ctx.moveTo(sp[0], sp[1]);
        for (let k = 2; k < sp.length; k += 2) ctx.lineTo(sp[k], sp[k + 1]);
        ctx.stroke();
      }
      if (ycut !== null) continue;
      // arrowhead
      const m = sp.length;
      if (m >= 4) {
        const ex = sp[m - 2], ey = sp[m - 1];
        let px = sp[m - 4], py = sp[m - 3];
        const d = Math.hypot(ex - px, ey - py) || 1;
        const ux = (ex - px) / d, uy = (ey - py) / d, s = 9;
        ctx.fillStyle = C.t[a];
        ctx.beginPath();
        ctx.moveTo(ex, ey);
        ctx.lineTo(ex - s * ux + s * 0.45 * uy, ey - s * uy - s * 0.45 * ux);
        ctx.lineTo(ex - s * ux - s * 0.45 * uy, ey - s * uy + s * 0.45 * ux);
        ctx.closePath();
        ctx.fill();
      }
      // endpoint ring
      const j = S.web.trips[a].perm[i];
      ctx.beginPath();
      ctx.arc(T.sx(L.bp[2 * j]), T.sy(L.bp[2 * j + 1]), 7, 0, 2 * Math.PI);
      ctx.lineWidth = 2.2;
      ctx.stroke();
    }
    ctx.globalAlpha = 1;
    ctx.beginPath();
    ctx.arc(T.sx(L.bp[2 * i]), T.sy(L.bp[2 * i + 1]), 7.5, 0, 2 * Math.PI);
    ctx.strokeStyle = C.accent;
    ctx.lineWidth = 3;
    ctx.stroke();
  }

    }
  }

  function permRowAt(a, ev) {
    const g = permGeom[a];

  }

  const VIRIDIS = [[68, 1, 84], [59, 82, 139], [33, 145, 140], [94, 201, 98], [253, 231, 37]];
  function viridis(t) {
    const s = Math.max(0, Math.min(1, t)) * (VIRIDIS.length - 1);
    const k = Math.min(VIRIDIS.length - 2, Math.floor(s)), f = s - k;
    const a = VIRIDIS[k], b = VIRIDIS[k + 1];
    return [a[0] + f * (b[0] - a[0]), a[1] + f * (b[1] - a[1]), a[2] + f * (b[2] - a[2])];
  }

  function nearestBoundary(mx, my) {
    if (!T || !S.web) return -1;
    const L = getLayout(S.view);
    let best = -1, bd = 14 * 14;
    for (let i = 0; i < S.n; i++) {
      const dx = T.sx(L.bp[2 * i]) - mx, dy = T.sy(L.bp[2 * i + 1]) - my;
      const d = dx * dx + dy * dy;
      if (d < bd) { bd = d; best = i; }
    }
    return best;
  }

  function nearestCrossing(mx, my) {
    if (!T || !S.web) return -1;
    const L = getLayout(S.view), G = S.web.G;
    let best = -1, bd = 10 * 10;
    for (let x = 0; x < G.nx; x++) {
      if (S.crossVisible && !S.crossVisible(x)) continue;
      const dx = T.sx(L.xp[2 * x]) - mx, dy = T.sy(L.xp[2 * x + 1]) - my;
      const d = dx * dx + dy * dy;
      if (d < bd) { bd = d; best = x; }
    }
    return best;
  }

    if (!T) return;

    const z = Math.max(0.5, Math.min(400, S.zoom * factor));
    const kNew = T.k / S.zoom * z;
    S.zoom = z;
    S.panX = mx - (wx - T.cx) * kNew - T.cw / 2;
