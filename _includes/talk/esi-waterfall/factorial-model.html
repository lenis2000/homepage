Factorial Schur Process [Li, in prep.]

Factorial Schur functions \(s_\lambda(x\,|\,y)\) and duals \(\check s_\lambda(w\,|\,y)\): partition functions of a 5-vertex model (nonintersecting paths) on a half-strip, column parameters \(y_1,y_2,\ldots\)
\(\displaystyle \sum_{\lambda} s_\lambda(x_1,\ldots,x_N\,|\,y)\,\check s_\lambda(w_1,\ldots,w_M\,|\,y) = \prod_{i=1}^{N}\prod_{j=1}^{M}\frac{1}{w_j-x_i}\)
Cauchy identity [Aggarwal-Borodin-P.-Wheeler 2023]: right-hand side independent of \(y\)
Process on two-sided interlacing sequences \(\varnothing \prec \lambda^{(1)} \prec \cdots \prec \lambda^{(N)} = \mu^{(M)} \succ \cdots \succ \mu^{(1)} \succ \varnothing\):
\(\displaystyle \mathrm{Prob} \propto \prod_{j=1}^{M} \check s_{\mu^{(j)}/\mu^{(j-1)}}(w_j\,|\,y) \prod_{i=1}^{N} s_{\lambda^{(i)}/\lambda^{(i-1)}}(x_i\,|\,y)\)
Waterfall specialization, \(q\in(0,1)\) fixed, \(\alpha>0\), \(\beta>1\):
\(x_i = 1,\qquad y_k = \alpha\, q^{k-M},\qquad w_j = \beta\, q^{j-M}\)
Lozenge tilings with Gibbs ratios of \(q\)-Racah type: moving \(\mu_i^{(j)}\mapsto\mu_i^{(j)}+1\) (neighbors fixed) changes the weight by
\(\displaystyle \frac{\beta q^{j+1} + \alpha q^{\mu_i+N+1-i}}{\beta q^{j} + \alpha q^{\mu_i+N+2-i}}\)
