Bulk Limit: an Explicit Waterfall Kernel [Li, in prep.]

{% include talk/esi-waterfall/factorial-phase-svg.html mode="bulk" %}
Theorem [Li, in prep.] \(N=\lfloor KM\rfloor\), \((t,z)\) in the bulk, local shifts \((\Delta t_a,\Delta z_a)\), \(r_a=\Delta t_a+\Delta z_a\). Along subsequences where an integer phase \(\theta_M\to\theta\), the kernel converges (up to conjugation) to
\[\mathcal{K}_\theta = -\sum_{\ell\in\mathbb{Z}} \operatorname*{Res}_{V=\beta q^{-\ell}} \left[\frac{1}{2\pi\mathrm{i}}\oint \frac{dU}{V-U}\,\frac{H(U)}{H(V)}\,\frac{U^{\theta+r_2-1}}{V^{\theta+r_1}}\right] - \mathbf{1}_{\Delta t_1>\Delta t_2}\mathbf{1}_{r_1=r_2}\]
\(H(U)=\Theta_q(U/\beta)\,\Theta_q(-U/\alpha)\),  \(\Theta_q(c)=(c;q)_\infty(q/c;q)_\infty\)
Properties
  • Dimensional collapse: depends on the local position only through \(r=\Delta t+\Delta z\) (time enters only via the ordering indicator)
  • Two-periodicity: \(\mathcal{K}_{\theta+2m}=q^{m(r_2-r_1)}\mathcal{K}_\theta\), so the limit depends only on the parity of \(\lfloor tM\rfloor+\lfloor zM\rfloor-\lfloor KM\rfloor\); invariant under shifts \((a,b)\) with \(a+b\) even
  • Frozen regions: fully packed for \(t+z<K\); density \(\le Ce^{-cM}\) for \(|t-z|>K\)
