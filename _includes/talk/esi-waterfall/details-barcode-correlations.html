Barcode: Correlations and Height Function

Correlations
\(\displaystyle \operatorname{Cov}\bigl(\mathbf{1}_{\mathrm{barcode}}(0), \mathbf{1}_{\mathrm{barcode}}(t)\bigr) = -\mathcal{K}^{\mathrm{barcode}}_{(M)}(0,t)^2\)
Plot of \(\log|\mathcal{K}^{\mathrm{barcode}}_{(M)}(0,t)| / \log q\) for \(q = \tfrac17, \tfrac27, \tfrac37, \tfrac47\) (\(\chi = \tfrac32\), \(M=20\)): linear growth \(\Rightarrow\) exponential decay of correlations (conjecturally)
Contrast: the sine process and ergodic Gibbs measures have polynomial decay of correlations.
Height function of the barcode \(\vec b = (b_1, b_2, \ldots)\), \(b_j \in \{0,1\}\):
\(\displaystyle h(t) = \sum\nolimits_{j=K}^{t} b_j, \qquad \text{fluctuations } h(t) - \tfrac{t}{2}\)
Sample: \((T,S,N) = (8L,4L,4L)\), \(L = 200\), \(q = \tfrac45\), \(\chi = 3\); moving average and envelopes.
Conjecture [Knizel-P. 2025]: fluctuations of the barcode height function grow slower than any power of \(L\).
