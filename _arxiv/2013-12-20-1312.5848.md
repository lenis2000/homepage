{% raw %}<p>The partition function of the Chern-Simons theory on the three-sphere with the unitary group <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>U</mi><mo stretchy="false">(</mo><mi>N</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">U(N)</annotation></semantics></math></span> provides a one-matrix model. The corresponding <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>N</mi></mrow><annotation encoding="application/x-tex">N</annotation></semantics></math></span>-particle system can be mapped to the determinantal point process whose correlation kernel is expressed by using the Stieltjes-Wigert orthogonal polynomials. The matrix model and the point process are regarded as <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>q</mi></mrow><annotation encoding="application/x-tex">q</annotation></semantics></math></span>-extensions of the random matrix model in the Gaussian unitary ensemble and its eigenvalue point process, respectively. We prove the convergence of the <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>N</mi></mrow><annotation encoding="application/x-tex">N</annotation></semantics></math></span>-particle system to an infinite-dimensional determinantal point process in <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>N</mi><mo>→</mo><mi mathvariant="normal">∞</mi></mrow><annotation encoding="application/x-tex">N \to \infty</annotation></semantics></math></span>, in which the correlation kernel is expressed by Jacobi's theta functions. We show that the matrix model obtained by this limit realizes the oscillatory matrix model in Chern-Simons theory discussed by de Haro and Tierz.</p>{% endraw %}
