{% raw %}<p>We provide a combinatorial description of exclusion statistics in terms of minimal difference <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>p</mi></mrow><annotation encoding="application/x-tex">p</annotation></semantics></math></span> partitions. We compute the probability distribution of the number of parts in a random minimal <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>p</mi></mrow><annotation encoding="application/x-tex">p</annotation></semantics></math></span> partition. It is shown that the bosonic point <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>p</mi><mo>=</mo><mn>0</mn></mrow><annotation encoding="application/x-tex"> p=0</annotation></semantics></math></span> is a repulsive fixed point for which the limiting distribution has a Gumbel form. For all positive <span class="katex"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>p</mi></mrow><annotation encoding="application/x-tex">p</annotation></semantics></math></span> the distribution is shown to be Gaussian.</p>{% endraw %}
